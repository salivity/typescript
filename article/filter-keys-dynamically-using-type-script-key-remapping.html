Filter Keys Dynamically Using TypeScript Key Remapping

TypeScript allows developers to transform and filter object keys dynamically at compile time by combining mapped types with the as remapping clause. This article demonstrates how to selectively remove keys from an object type by pairing key remapping with conditional types, utilizing TypeScript's behavior where keys mapped to the never type are completely omitted from the resulting structure.

The Core Mechanism: Remapping to never

TypeScript 4.1 introduced the as clause in mapped types, enabling key remapping. To filter out a key, you use a conditional type to check whether the key meets your removal criteria. If the condition matches the keys you want to omit, you evaluate the key to never. TypeScript interprets a mapped key that evaluates to never as an instruction to drop that property entirely.

type FilteredType<T> = {
  [K in keyof T as Condition ? never : K]: T[K];
};

Filtering Keys by Key Name

You can filter keys dynamically based on their property names using template literal types or union checks. For example, if you want to remove any properties that begin with an underscore:

type OmitUnderscoreKeys<T> = {
  [K in keyof T as K extends `_${string}` ? never : K]: T[K];
};

interface User {
  id: string;
  name: string;
  _passwordHash: string;
  _internalId: number;
}

// Resulting type: { id: string; name: string; }
type PublicUser = OmitUnderscoreKeys<User>;

In this implementation, K extends_${string}`checks if the key begins with an underscore. If true, the key resolves tonever, omitting it from thePublicUser` interface.

Filtering Keys by Value Type

Key remapping also enables filtering based on the data type associated with each property. You can inspect T[K] to decide whether to retain or discard the key.

Keeping Only Specific Types

To create a type that only retains properties of a specific type (such as strings):

type PickPropertiesByType<T, ValueType> = {
  [K in keyof T as T[K] extends ValueType ? K : never]: T[K];
};

interface Product {
  id: number;
  title: string;
  description: string;
  inStock: boolean;
}

// Resulting type: { title: string; description: string; }
type StringOnlyProduct = PickPropertiesByType<Product, string>;

Removing Methods or Functions

Conversely, you can omit properties that match certain types, such as filtering out functions to extract pure data properties:

type OmitMethods<T> = {
  [K in keyof T as T[K] extends Function ? never : K]: T[K];
};

interface Service {
  apiKey: string;
  retries: number;
  connect(): void;
  disconnect(): void;
}

// Resulting type: { apiKey: string; retries: number; }
type ServiceData = OmitMethods<Service>;

Combining Multiple Filtering Conditions

Because the as clause supports any standard conditional type, you can chain conditions or combine union types to create advanced filters:

type ComplexFilter<T> = {
  [K in keyof T as K extends `temp_${string}`
    ? never
    : T[K] extends Function | symbol
    ? never
    : K]: T[K];
};

This pattern checks the key name first, then evaluates the property type, ensuring that any temporary properties or non-serializable fields are discarded systematically.
