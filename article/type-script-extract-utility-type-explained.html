TypeScript Extract Utility Type Explained

The Extract utility type in TypeScript is a built-in tool designed to filter union types by pulling out only the members that are assignable to a specified type. This article covers the syntax of Extract, how it operates using conditional types under the hood, and practical examples demonstrating how to narrow both primitive unions and complex discriminated union objects.

What Is Extract?

The primary purpose of Extract<Type, Union> is to construct a new type by selecting from Type all union members that are assignable to Union. It acts as an allowlist for union types, allowing developers to isolate shared or desired subtypes without redefining them manually.

The syntax is:

type Result = Extract<Type, Union>;
  • Type: The original union type you want to filter.
  • Union: The target type or set of types you want to keep.

How Extract Works

Extract is implemented using TypeScript's distributive conditional types:

type Extract<T, U> = T extends U ? T : never;

When evaluated, TypeScript iterates over each member of the union T. If a member can be assigned to U, it is retained. If not, it evaluates to never, which is automatically removed from the resulting union.

Basic Example: Filtering Primitives

You can use Extract to retain specific literal types or data types from a broader union.

type Status = "success" | "warning" | "error" | 404 | 500;

// Extract only string literals
type StringStatus = Extract<Status, string>;
// Equivalent to: "success" | "warning" | "error"

// Extract specific values
type ErrorStatus = Extract<Status, "error" | 500>;
// Equivalent to: "error" | 500

Advanced Example: Discriminated Unions

Extract is frequently used with discriminated unions, such as action types in state management or event-driven architectures.

type AppEvent =
  | { type: "click"; x: number; y: number }
  | { type: "hover"; elementId: string }
  | { type: "keypress"; key: string };

// Extract only the 'click' event object
type ClickEvent = Extract<AppEvent, { type: "click" }>;

/*
Equivalent to:
{
  type: "click";
  x: number;
  y: number;
}
*/

In this example, TypeScript matches the shape { type: "click" } against each object in AppEvent and retains the full type definition of matching variants.

Extract vs. Exclude

Extract and Exclude are opposite utility types:

  • Extract<T, U>: Keeps members of T that are assignable to U.
  • Exclude<T, U>: Removes members of T that are assignable to U.
type Letters = "a" | "b" | "c";

type Extracted = Extract<Letters, "a" | "f">; // "a"
type Excluded = Exclude<Letters, "a" | "f">;  // "b" | "c"

Common Use Cases

  • Handling specific event payloads: Isolating a single event or subset of events from a centralized union of all application events.
  • Narrowing function inputs: Ensuring a function or component prop only accepts an approved subset of an existing union.
  • Working with external libraries: Slicing large unions provided by third-party type definitions into smaller, application-specific types without copying code.
