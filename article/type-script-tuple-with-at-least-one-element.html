TypeScript Tuple with at Least One Element

In TypeScript, you can enforce that an array contains at least one item by combining tuple types with the rest element syntax. This pattern, commonly written as [T, ...T[]], creates a non-empty array type that guarantees compile-time safety by rejecting empty array literals and invalid inputs. This article covers the exact syntax, how it works under the hood, and how to implement it in your code.

The Basic Syntax

To define an array type that requires at least one element, declare a tuple where the first element is a specific type and the second element is a rest spread of that same type's array:

type NonEmptyArray<T> = [T, ...T[]];

In this definition:

  • T requires the first element (at index 0) to exist and match type T.
  • ...T[] uses the rest element operator to allow zero or more additional elements of type T to follow.

Practical Example

You can apply this syntax directly to variable declarations or custom utility types:

// Define a non-empty array of numbers
type NonEmptyNumberArray = [number, ...number[]];

// Valid assignments
const validSingle: NonEmptyNumberArray = [10];
const validMultiple: NonEmptyNumberArray = [10, 20, 30];

// Invalid assignment (Causes a TypeScript compilation error)
// Error: Source has 0 element(s) but target requires 1.
const invalidEmpty: NonEmptyNumberArray = [];

Using Non-Empty Tuples in Functions

A common use case is preventing functions from receiving empty arrays, such as mathematical operations that require at least one value:

function calculateAverage(numbers: [number, ...number[]]): number {
  const sum = numbers.reduce((acc, curr) => acc + curr, 0);
  return sum / numbers.length;
}

calculateAverage([5]);           // Valid, returns 5
calculateAverage([10, 20, 30]);  // Valid, returns 20
calculateAverage([]);            // Compile-time error

Requiring Multiple Minimum Elements

This syntax scales to enforce any minimum number of elements. To enforce at least two or more elements, specify additional explicit elements before the rest spread:

// Requires at least two elements
type AtLeastTwo<T> = [T, T, ...T[]];

const coordinates: AtLeastTwo<number> = [10, 20];       // Valid
const path: AtLeastTwo<number> = [10, 20, 30, 40];      // Valid
const singlePoint: AtLeastTwo<number> = [10];           // Error: Source has 1 element(s) but target requires 2.
