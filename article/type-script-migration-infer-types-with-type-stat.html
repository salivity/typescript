TypeScript Migration: Infer Types with TypeStat

Migrating a legacy JavaScript codebase to TypeScript can be an overwhelming, manual process that often leads to developer fatigue and widespread use of the any type. This article explores how TypeStat, an open-source automation tool, streamlines this migration by analyzing Abstract Syntax Trees (ASTs) to automatically infer and inject accurate TypeScript types directly into your code.

Automated Type Inference from Usage

The core challenge of converting JavaScript to TypeScript is determining the correct types for variables, parameters, and object properties without explicit declarations. TypeStat solves this by analyzing how variables are actually used across the codebase:

  • Variable Assignments: It detects initial values, subsequent reassignments, and mutations to infer unions or narrow down primitive types.
  • Function Call Sites: TypeStat inspects the arguments passed to functions across all callers to infer the appropriate parameter types and return types.
  • Property Access: When objects are passed into functions or manipulated dynamically, TypeStat identifies the accessed properties and constructs corresponding object shapes or interface declarations.

Upgrading JSDoc to Native TypeScript

Many legacy codebases already possess some degree of documentation via JSDoc comments. Instead of requiring developers to manually translate these comments into TypeScript syntax, TypeStat parses existing @param, @returns, and @type tags and directly converts them into native TypeScript annotations. This preserves the original developer intent while modernizing the syntax automatically.

Eliminating Implicit any

A standard migration step involves enabling noImplicitAny in tsconfig.json. This often surfaces thousands of compilation errors overnight. TypeStat can be configured to target these exact errors, generating appropriate types or fallback types automatically. By systematically resolving missing type definitions, it allows teams to progress toward enabling TypeScript's strict mode significantly faster.

Safe, Incremental Execution

Migrating an entire project in a single pass often introduces merge conflicts and hard-to-track bugs. TypeStat operates via a configurable typestat.json file, allowing teams to adopt an incremental approach:

  • Targeted Rules: You can configure TypeStat to run one specific transformation at a time, such as inferring parameter types or adding missing property types.
  • File Scoping: Transformations can be scoped to specific directories or individual files, allowing teams to test, review, and commit changes gradually.
  • Compiler Integration: TypeStat integrates with the TypeScript compiler API to ensure that transformations produce syntactically valid code that satisfies the compiler's type checker.

By automating the mechanical aspects of type inference, TypeStat minimizes the manual burden of JavaScript-to-TypeScript migrations, reduces the occurrence of loosely typed code, and shortens the path to a fully typed codebase.
