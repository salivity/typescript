Understanding Index Access Types in TypeScript

Index access types, also known as lookup types, allow you to query and reuse the type of a specific property from another type in TypeScript. By mirroring the bracket notation used to access object properties at runtime, index access types prevent code duplication and ensure strict type consistency throughout your codebase. This guide explains what index access types are, how to declare them using standard bracket notation, and how to apply them to nested objects, unions, and arrays.

What Are Index Access Types?

In TypeScript, an index access type looks up a specific property on another type using the syntax Type[Key]. Instead of manually redefining a type that already exists as a property of an interface or type alias, you extract it directly. This establishes a single source of truth: if the original type changes, any dependent index access types update automatically.

Basic Declaration and Syntax

To declare an index access type, supply the parent type followed by the property name in square brackets. The key must be a valid type itself, typically a string literal type representing the property name.

type User = {
  id: string;
  name: string;
  age: number;
};

// Declaring index access types
type UserId = User['id'];     // string
type UserAge = User['age'];   // number

Because the index itself is a type, you cannot pass a runtime variable directly into the brackets unless you use the typeof operator.

const key = 'name';

// Error: Cannot find name 'key'
// type UserName = User[key];

// Correct: Use typeof to refer to the type of the constant
type UserName = User[typeof key]; // string

Accessing Nested Object Types

Index access notation can be chained to extract types from deeply nested data structures.

type Company = {
  name: string;
  location: {
    city: string;
    coordinates: {
      lat: number;
      lng: number;
    };
  };
};

// Extracting deeply nested types
type Coordinates = Company['location']['coordinates']; // { lat: number; lng: number; }
type Latitude = Company['location']['coordinates']['lat']; // number

Accessing Multiple Keys and Unions

You can look up multiple properties simultaneously by passing a union of keys. The resulting type will be a union of the corresponding property types.

type Product = {
  id: number;
  sku: string;
  inStock: boolean;
};

// Returns: number | string
type ProductIdentifier = Product['id' | 'sku'];

When combined with the keyof operator, an index access type can dynamically extract a union of all property value types within an object.

// Returns: number | string | boolean
type ProductValues = Product[keyof Product];

Index Access Types with Arrays and Tuples

Index access types also work with array and tuple types using the number keyword or numeric literal types.

Arrays

Using [number] extracts the type of the array's elements:

const roles = ['admin', 'editor', 'viewer'] as const;

// Extract the union of all string literals in the array
type Role = typeof roles[number]; // "admin" | "editor" | "viewer"

Tuples

For tuples, you can access specific elements by their numeric index, or use number to get a union of all possible tuple values:

type KeyValuePair = [string, number];

type KeyType = KeyValuePair[0];       // string
type ValueType = KeyValuePair[1];     // number
type AllElementTypes = KeyValuePair[number]; // string | number
