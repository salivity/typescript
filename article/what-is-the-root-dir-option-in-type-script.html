What Is the rootDir Option in TypeScript?

The rootDir compiler option in TypeScript controls the directory structure of compiled JavaScript files when paired with outDir. Rather than determining which files are included in compilation, rootDir defines the expected root path of your source code to ensure that the output directory mirrors the input directory predictably, preventing accidental restructuring of build artifacts.

The Core Purpose of rootDir

When the TypeScript compiler (tsc) outputs compiled JavaScript using the outDir setting, it must decide how to mirror the source folder structure in the target folder.

By default, if rootDir is not specified, TypeScript automatically computes the "longest common path" among all input TypeScript files to serve as the root. For example, if all your code lives inside src/, TypeScript uses src/ as the base, outputting src/index.ts to dist/index.js.

However, this automatic behavior can lead to unexpected build breakage. If you import a file outside src/—such as a file in a shared/ directory, a root configuration script, or a test file—the longest common path changes. As a result, the output becomes dist/src/index.js and dist/shared/util.js. This subtle shift breaks relative import paths in your production bundle.

Setting rootDir explicitly prevents this issue by enforcing a fixed base directory.

Enforcing Project Boundaries

When you define "rootDir": "./src", you explicitly instruct the TypeScript compiler that the root of your source tree is ./src.

If any file included in the compilation falls outside of the path defined by rootDir, the compiler will refuse to compile and throw an error:

error TS6059: File '...' is not under 'rootDir' '...'. 'rootDir' is expected to contain all source files.

This acts as an architectural guardrail, guaranteeing that the structure inside outDir will always match the structure inside rootDir exactly.

Example Configuration

Here is how rootDir is typically configured in a tsconfig.json file:

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "commonjs",
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src/**/*"]
}

With this configuration:

  • src/index.ts compiles to dist/index.js.
  • src/components/button.ts compiles to dist/components/button.js.

Common Misconceptions

  • It does not include or exclude files: rootDir does not define which files are part of your project. Inclusion and exclusion are handled exclusively by the files, include, and exclude settings.
  • It is not the same as rootDirs: The plural rootDirs option is used to merge multiple virtual directories into a single path for module resolution purposes, whereas rootDir is solely concerned with physical output mapping.
