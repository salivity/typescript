Strongly Typed Object.keys in TypeScript

By default, TypeScript's Object.keys() returns string[] rather than an array of an object's specific keys. This article explains why TypeScript implements this behavior and demonstrates how to create a lightweight, strongly-typed wrapper function that returns typed keys for easier and safer object manipulation.

Why Object.keys Returns string[]

TypeScript deliberately types Object.keys(obj) as string[] due to structural subtyping. In TypeScript, an object may contain more runtime properties than its static type definition specifies. If TypeScript typed the output as (keyof T)[], accessing or modifying runtime properties not present in the type could lead to runtime errors.

However, in many day-to-day scenarios, developers work with well-defined objects and need direct access to the typed keys without manually casting the result every time.

Implementing the Wrapper Function

A strongly-typed wrapper leverages generics and type casting. Since Object.keys only returns string properties (excluding symbols and stringifying numeric indices), the most accurate type representation extracts only string keys:

export function getTypedKeys<T extends object>(obj: T): Array<Extract<keyof T, string>> {
  return Object.keys(obj) as Array<Extract<keyof T, string>>;
}

If you prefer a simpler signature and your types only use standard string keys, you can also write:

export function typedKeys<T extends object>(obj: T): (keyof T)[] {
  return Object.keys(obj) as (keyof T)[];
}

Usage Example

Consider a scenario where you want to iterate over an object's keys and access its values:

interface UserProfile {
  id: string;
  name: string;
  age: number;
}

const user: UserProfile = {
  id: "u123",
  name: "Alex",
  age: 30,
};

// Standard Object.keys requires a type assertion to index the object:
// Object.keys(user).forEach((key) => user[key as keyof UserProfile]);

// Using the typed wrapper:
const keys = getTypedKeys(user); // Type: ("id" | "name" | "age")[]

keys.forEach((key) => {
  console.log(`${key}: ${user[key]}`); // No TypeScript error
});

Considerations

While this wrapper improves developer ergonomics by enabling autocomplete and eliminating manual casts, use it with caution when handling objects that originate from external inputs, APIs, or extended types where excess runtime properties might be present.
