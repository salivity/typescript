Typing Svelte Props and Events with TypeScript

Svelte integrates directly with TypeScript to provide end-to-end type safety for component interfaces, reducing runtime bugs and improving developer experience. This article explains how to type component props and events in Svelte, covering both modern Svelte 5 syntax using runes and the traditional Svelte 3/4 approach.

Typing Component Props

To enable TypeScript in a Svelte component, declare <script lang="ts"> in the component file.

Svelte 5 (Runes)

In Svelte 5, component props are declared using the $props() rune. You define an interface or type and apply it directly to the destructured $props() declaration.

<script lang="ts">
  interface Props {
    title: string;
    count?: number;
    disabled?: boolean;
  }

  let { title, count = 0, disabled = false }: Props = $props();
</script>

<h1>{title}</h1>
<p>Count: {count}</p>

Svelte 3 and 4 (Export Syntax)

In earlier versions, props are defined using the export let keyword, with TypeScript type annotations appended to each variable.

<script lang="ts">
  export let title: string;
  export let count: number = 0;
  export let disabled: boolean = false;
</script>

<h1>{title}</h1>
<p>Count: {count}</p>

Typing Component Events

Typing events ensures that callers provide the correct event handlers and payload shapes.

Svelte 5 (Callback Props)

Svelte 5 shifts away from custom event dispatching in favor of standard callback functions passed as props.

<script lang="ts">
  interface Props {
    onSave: (payload: { id: number; text: string }) => void;
    onCancel?: () => void;
  }

  let { onSave, onCancel }: Props = $props();

  function handleSave() {
    onSave({ id: 1, text: "Updated" });
  }
</script>

<button onclick={handleSave}>Save</button>
<button onclick={onCancel}>Cancel</button>

Svelte 3 and 4 (createEventDispatcher)

In Svelte 3 and 4, custom events are emitted using createEventDispatcher. You provide a type map specifying the event name and the payload type as a generic parameter.

<script lang="ts">
  import { createEventDispatcher } from 'svelte';

  const dispatch = createEventDispatcher<{
    save: { id: number; text: string };
    cancel: null;
  }>();

  function handleSave() {
    dispatch('save', { id: 1, text: "Updated" });
  }

  function handleCancel() {
    dispatch('cancel');
  }
</script>

<button on:click={handleSave}>Save</button>
<button on:click={handleCancel}>Cancel</button>

Typing Generic Components

When a component needs to handle dynamic data types—such as a generic list or dropdown—you can declare generic types using the generics attribute on the script tag.

<script lang="ts" generics="T extends { id: string | number }">
  interface Props {
    items: T[];
    onSelect: (item: T) => void;
  }

  let { items, onSelect }: Props = $props();
</script>

<ul>
  {#each items as item}
    <li onclick={() => onSelect(item)}>
      {item.id}
    </li>
  {/each}
</ul>

Using these patterns guarantees accurate autocompletion, compile-time validation, and reliable refactoring when consuming Svelte components across your application.
