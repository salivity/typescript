TypeScript Mapped Types: Transform Object Structures

Mapped types in TypeScript provide a powerful mechanism to create new types by iterating over the property keys of an existing type and transforming them systematically. This article explores how mapped types operate, covering the fundamental iteration syntax, the addition or removal of property modifiers like readonly and optional flags, key remapping techniques introduced in modern TypeScript, and how built-in utility types leverage this pattern to enforce type safety across complex data models.

Understanding the Core Syntax

Mapped types build upon index signatures and use the keyof operator to iterate over property keys. The syntax closely resembles a loop:

type FeatureFlags = {
  darkMode: boolean;
  betaAccess: boolean;
};

type ReadonlyFlags = {
  readonly [K in keyof FeatureFlags]: FeatureFlags[K];
};

In this syntax:

  • keyof FeatureFlags generates the union 'darkMode' | 'betaAccess'.
  • [K in ...] iterates through each key in that union.
  • FeatureFlags[K] uses indexed access to retain the original value type (boolean).

Transforming Property Modifiers

Mapped types allow you to modify property attributes by adding or removing the readonly and ? (optional) modifiers using + (implied if omitted) or - prefixes.

Making Properties Optional or Required

To make all properties optional, append ?:

type Optional<T> = {
  [K in keyof T]?: T[K];
};

To strip the optional flag and enforce that all properties are strictly required, use -?:

type Concrete<T> = {
  [K in keyof T]-?: T[K];
};

Adding or Removing Readonly

To prevent mutations, prefix with readonly:

type Immutable<T> = {
  readonly [K in keyof T]: T[K];
};

To remove immutability constraints, use -readonly:

type Mutable<T> = {
  -readonly [K in keyof T]: T[K];
};

Transforming Value Types

Mapped types can map existing keys to entirely new value types, allowing structural transformations such as turning properties into functions, promises, or validation schemas.

type User = {
  id: string;
  age: number;
};

// Transform all property values into functions returning that value
type Getters<T> = {
  [K in keyof T]: () => T[K];
};

type UserGetters = Getters<User>;
// Result:
// {
//   id: () => string;
//   age: () => number;
// }

Key Remapping with the as Clause

TypeScript allows you to transform key names directly using an as clause within the mapped type declaration. This is often combined with template literal types.

Renaming Properties

type AddGetters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type UserAccessor = AddGetters<User>;
// Result:
// {
//   getId: () => string;
//   getAge: () => number;
// }

Filtering Keys Using never

You can conditionally filter out properties during transformation by mapping keys to never:

type OnlyStrings<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};

type UserStrings = OnlyStrings<User>;
// Result:
// {
//   id: string;
// }

Standard Utility Types

TypeScript includes several built-in utility types that are implemented directly via mapped types:

  • Partial<T>: Marks all properties as optional using [P in keyof T]?: T[P].
  • Required<T>: Removes optional flags with [P in keyof T]-?: T[P].
  • Readonly<T>: Freezes properties using readonly [P in keyof T]: T[P].
  • Record<K, T>: Constructs an object type with specified keys K and values T using [P in K]: T.
  • Pick<T, K>: Selects a subset of properties using [P in K]: T[P].

Mapped types eliminate the need for manual, redundant interface declarations, providing a single source of truth when adapting data structures across application layers.
