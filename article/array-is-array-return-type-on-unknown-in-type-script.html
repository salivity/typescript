Array.isArray Return Type on Unknown in TypeScript

In TypeScript, when Array.isArray() is called on a value of type unknown, its compile-time return type is the type predicate arg is any[], while its runtime return type is a standard boolean. As a result of this type predicate, passing an unknown variable into Array.isArray() inside a conditional statement automatically narrows that variable's type from unknown to any[] within the truthy branch.

The Standard Library Signature

TypeScript defines Array.isArray in its core library definitions (lib.es5.d.ts) as follows:

interface ArrayConstructor {
    isArray(arg: any): arg is any[];
}

Because TypeScript uses the type predicate arg is any[], the function does not merely return boolean to the compiler. Instead, it informs the type checker that whenever the function evaluates to true, the argument provided can be treated as an array of any.

Runtime vs. Compile-Time Return Types

  • Runtime Return Type: boolean (true if the value is an array, false otherwise).
  • Compile-Time Return Type: arg is any[] (a boolean type predicate).

Type Narrowing Behavior

When applied to an unknown variable, the narrowing takes effect immediately inside the conditional check:

function processValue(value: unknown) {
    if (Array.isArray(value)) {
        // value is narrowed to any[]
        console.log(value.length); 
        console.log(value[0].nonExistentMethod()); // Permitted by compiler due to `any`
    } else {
        // value remains unknown
    }
}

Safety Considerations: any[] vs. unknown[]

TypeScript narrows to any[] rather than unknown[] primarily for backward compatibility. However, this introduces potential runtime errors because items accessed from any[] bypass type checking.

To enforce strict type safety where elements inside the array remain unknown until checked, you can define a custom, safer type guard:

function isSafeArray(value: unknown): value is unknown[] {
    return Array.isArray(value);
}

function processStrict(value: unknown) {
    if (isSafeArray(value)) {
        // value is narrowed to unknown[]
        console.log(value.length); // Allowed
        // value[0].nonExistentMethod(); // Error: Object is of type 'unknown'
    }
}
