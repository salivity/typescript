Extract Properties by Value Type in TypeScript

Extracting properties from an object type based on their value types is a common TypeScript pattern used to build flexible, type-safe utilities. By combining mapped types, conditional types, and key remapping via the as clause, you can inspect each property in an interface, evaluate whether its value matches a specific target type, and extract either the matching object shape or the property keys themselves.

The Modern Solution: Key Remapping

TypeScript 4.1 introduced key remapping in mapped types, providing the cleanest syntax to filter properties by their value types.

type PickByValue<T, ValueType> = {
  [K in keyof T as T[K] extends ValueType ? K : never]: T[K];
};

How It Works:

  1. [K in keyof T]: Iterates over every key K in the type T.
  2. as T[K] extends ValueType ? K : never: Inspects the value type T[K]. If T[K] is assignable to ValueType, the key K is preserved; otherwise, it resolves to never, omitting the key from the resulting type.
  3. : T[K]: Retains the original value type for the preserved keys.

Example Usage

Consider a User interface with mixed property types:

interface User {
  id: number;
  name: string;
  email: string;
  age: number;
  isActive: boolean;
  login: () => void;
}

1. Extract All String Properties

type StringProperties = PickByValue<User, string>;
// Result:
// {
//   name: string;
//   email: string;
// }

2. Extract All Function Properties

type FunctionProperties = PickByValue<User, Function>;
// Result:
// {
//   login: () => void;
// }

Extracting Property Keys by Value Type

If you need only the property names (keys) as a union instead of an entire object shape, use an indexed access type combined with a conditional mapped type:

type KeysByValue<T, ValueType> = {
  [K in keyof T]: T[K] extends ValueType ? K : never;
}[keyof T];

Example:

type NumericKeys = KeysByValue<User, number>;
// Result: "id" | "age"

In this pattern, non-matching keys produce a value of never. Indexing the type with [keyof T] collects all resulting types into a union, automatically filtering out never.

Handling Strict Value Equality

The extends keyword checks for assignability rather than strict equality. If you want to match a value type strictly (for example, to exclude string | number when searching specifically for string), implement an exact match utility:

type Exact<T, U> = [T] extends [U] ? ([U] extends [T] ? true : false) : false;

type PickByExactValue<T, ValueType> = {
  [K in keyof T as Exact<T[K], ValueType> extends true ? K : never]: T[K];
};

This ensures that only properties with identical types to the target value type are retained.
