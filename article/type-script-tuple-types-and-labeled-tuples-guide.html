TypeScript Tuple Types and Labeled Tuples Guide

This article provides an overview of tuple types in TypeScript, detailing how they differ from standard arrays and why they are useful for enforcing strict data structures. It also covers labeled tuple elements, demonstrating how to declare them with clear syntax examples and explaining how they improve code readability and developer tooling.

What Are Tuple Types in TypeScript?

A tuple in TypeScript is a specialized array type that contains a fixed number of elements where each element has a known, specific type. Unlike standard arrays, which typically hold an arbitrary number of items of the same type (like number[] or string[]), tuples allow you to define the exact sequence and type of data stored at each index.

Tuples are declared using square bracket syntax with comma-separated types:

// A tuple containing exactly a string and a number
let user: [string, number];

// Valid assignment
user = ["Alice", 30];

// Error: Type 'number' is not assignable to type 'string'
user = [30, "Alice"];

// Error: Source has 3 elements, but target allows only 2
user = ["Alice", 30, true];

Tuples are particularly useful for representing structured data pairs or records, such as key-value pairs, coordinate systems [number, number], or return values from React hooks like useState.

How to Declare Labeled Tuples

TypeScript 4.0 introduced labeled tuple elements (named tuples). Labeled tuples allow you to assign a descriptive name to each element in the tuple type definition. These labels do not alter the runtime behavior of the tuple; they serve purely as inline documentation and enhance editor tooling, such as autocompletion and hover hints.

To declare a labeled tuple, prefix the element type with a label and a colon (label: Type):

type GeoPoint = [latitude: number, longitude: number];

type ResponseEntry = [status: number, message: string, isValid: boolean];

When initializing or using a labeled tuple, the syntax remains identical to standard arrays:

const point: GeoPoint = [37.7749, -122.4194];

Rules and Features of Labeled Tuples

  1. All-or-Nothing Rule: When using labeled tuples, every element in the tuple must have a label. You cannot label only some elements while leaving others unlabeled.

    // Error: Tuple members must all have names or all not have names
type InvalidTuple = [name: string, number];

  2. Optional Elements: You can mark labeled elements as optional by placing a question mark (?) after the label name.

    type UserProfile = [username: string, age?: number];

const userA: UserProfile = ["coder123"];
const userB: UserProfile = ["coder123", 25];

  3. Rest Elements: You can label rest elements using the spread operator (...).

    type StringList = [category: string, ...items: string[]];

const groceries: StringList = ["Groceries", "Milk", "Bread", "Eggs"];

  4. Function Parameters: Labeled tuples are frequently used to type function parameters and rest parameters, making the generated signatures much clearer in IDE tooltips:

    type ConnectionParams = [host: string, port: number, secure: boolean];

function connect(...args: ConnectionParams) {
  const [host, port, secure] = args;
  // ...
}

Labeled tuples clarify the purpose of positional data without requiring the overhead of refactoring an array structure into an object.
