How to Write Generic Components in TypeScript JSX

This guide explains how to define and use generic components in React with TypeScript JSX (.tsx). It covers the syntax for standard function declarations and arrow functions, demonstrates how to define generic prop interfaces, explores type constraints, and provides solutions for common parser ambiguities unique to JSX.

Generic Component with Function Declarations

The most straightforward way to write a generic component in TSX is using standard function syntax. You place the generic type parameter directly after the function name.

interface ListProps<T> {
  items: T[];
  renderItem: (item: T) => React.ReactNode;
}

function List<T>(props: ListProps<T>) {
  return (
    <ul>
      {props.items.map((item, index) => (
        <li key={index}>{props.renderItem(item)}</li>
      ))}
    </ul>
  );
}

Generic Component with Arrow Functions

When using arrow functions in a .tsx file, writing <T> causes a syntax conflict because the TypeScript compiler interprets <T> as an opening JSX tag rather than a type parameter.

To resolve this ambiguity, you can either add a trailing comma or explicitly extend a type such as unknown:

Method 1: Trailing Comma

const List = <T,>(props: ListProps<T>) => {
  return (
    <ul>
      {props.items.map((item, index) => (
        <li key={index}>{props.renderItem(item)}</li>
      ))}
    </ul>
  );
};

Method 2: Extending unknown

const List = <T extends unknown>(props: ListProps<T>) => {
  return (
    <ul>
      {props.items.map((item, index) => (
        <li key={index}>{props.renderItem(item)}</li>
      ))}
    </ul>
  );
};

Applying Generic Constraints

You can restrict the generic type to ensure incoming data contains required properties. This is done using the extends keyword.

interface Identifiable {
  id: string | number;
}

interface TableProps<T extends Identifiable> {
  data: T[];
  columns: (keyof T)[];
}

function Table<T extends Identifiable>({ data, columns }: TableProps<T>) {
  return (
    <table>
      <tbody>
        {data.map((row) => (
          <tr key={row.id}>
            {columns.map((col) => (
              <td key={String(col)}>{String(row[col])}</td>
            ))}
          </tr>
        ))}
      </tbody>
    </table>
  );
}

Using Generic Components in JSX

TypeScript can automatically infer generic types based on the props passed to the component:

interface User {
  id: number;
  name: string;
}

const users: User[] = [
  { id: 1, name: "Alice" },
  { id: 2, name: "Bob" },
];

// Type inference determines T is User
function App() {
  return <List items={users} renderItem={(user) => <span>{user.name}</span>} />;
}

If type inference fails or you need strict enforcement, you can explicitly pass the type argument to the JSX element:

function App() {
  return (
    <List<User>
      items={users}
      renderItem={(user) => <span>{user.name}</span>}
    />
  );
}
