TypeScript Type Predicate Function Signatures

In TypeScript, a type predicate function is a custom type guard used to narrow down the type of an object within conditional blocks. Its return type takes the explicit form parameterName is Type, signaling to the compiler that if the function returns true, the tested variable matches the specified type. This article breaks down the exact syntax, structural rules, and practical implementation of type predicate function signatures in TypeScript.

The Basic Function Signature

The signature of a type predicate function mirrors a standard boolean-returning function, with the exception of the return type annotation. Instead of returning boolean, the return type is written as parameterName is TargetType.

function isFish(pet: Fish | Bird): pet is Fish {
    return (pet as Fish).swim !== undefined;
}

In this signature:

  • pet is the name of the parameter being evaluated.
  • pet is Fish is the type predicate.
  • The function must return a standard runtime boolean (true or false).

Core Rules for the Signature

To construct a valid type predicate signature in TypeScript, three core conditions must be met:

  1. Parameter Reference: The identifier on the left of is must match the exact name of a parameter declared in the function's parameter list.
  2. Target Type: The type on the right of is must be a valid TypeScript type (an interface, union, primitive, or class).
  3. Boolean Return: The runtime body of the function must return a boolean expression. If it returns true, TypeScript narrows the parameter to the specified type in the calling scope; if false, it narrows it to the remaining alternative types.

Alternative Function Forms

Type predicates can also be defined using arrow functions, interface method signatures, and class methods.

Arrow Functions

const isString = (value: unknown): value is string => {
    return typeof value === "string";
};

Interfaces and Type Aliases

type TypeGuard<T> = (value: unknown) => value is T;

interface Validator {
    isValidUser(input: unknown): input is User;
}

Class Methods

When checking instances within object-oriented patterns, classes can use this is Type as the predicate:

class FileSystemNode {
    isFile(): this is FileNode {
        return this instanceof FileNode;
    }
}

Compiler Behavior

When a type predicate function is called within a conditional statement like an if block, TypeScript's control flow analysis automatically narrows the variable's type based on the result:

function processValue(val: unknown) {
    if (isString(val)) {
        // 'val' is strictly typed as 'string' inside this block
        console.log(val.toUpperCase());
    } else {
        // 'val' remains 'unknown' (or any remaining union types)
    }
}

Using value is Type bridges runtime condition checks with static type safety, preventing unnecessary manual type assertions (as Type) across your codebase.
