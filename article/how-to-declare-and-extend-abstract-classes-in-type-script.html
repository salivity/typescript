How to Declare and Extend Abstract Classes in TypeScript

This guide explains how to declare and extend abstract classes in TypeScript. Abstract classes act as base blueprints that cannot be instantiated directly, allowing developers to define common implementation details while enforcing specific method implementations in derived subclasses. You will learn the core syntax for defining abstract classes and methods, how to properly inherit them using the extends keyword, and the fundamental rules governing their usage.

Declaring an Abstract Class

An abstract class is declared using the abstract keyword before the class keyword. These classes can contain fully implemented members (concrete methods and properties) as well as method signatures without implementations (abstract methods).

abstract class Employee {
  // Concrete property
  constructor(public name: string, public id: number) {}

  // Concrete method (shared implementation)
  getDetails(): string {
    return `${this.name} (ID: ${this.id})`;
  }

  // Abstract method (must be implemented by derived classes)
  abstract calculatePay(): number;
}

Key rules for declaring abstract classes:

  • Cannot be instantiated: Attempting to run new Employee(...) will trigger a TypeScript compilation error (Cannot create an instance of an abstract class).
  • Abstract methods have no body: Abstract methods define the parameters and return type, ending with a semicolon instead of curly braces.
  • Access modifiers: Abstract methods can be marked as public or protected, but not private, because derived classes must be able to implement them.

Extending an Abstract Class

To use an abstract class, a concrete class must inherit from it using the extends keyword. The child class is required to implement all abstract methods defined in the parent class.

class FullTimeEmployee extends Employee {
  constructor(name: string, id: number, private annualSalary: number) {
    // Call the parent class constructor
    super(name, id);
  }

  // Implementing the abstract method
  calculatePay(): number {
    return this.annualSalary / 12;
  }
}

class HourlyEmployee extends Employee {
  constructor(
    name: string,
    id: number,
    private hourlyRate: number,
    private hoursWorked: number
  ) {
    super(name, id);
  }

  // Implementing the abstract method
  calculatePay(): number {
    return this.hourlyRate * this.hoursWorked;
  }
}

Instantiation and Polymorphism

Once the subclass implements every abstract member, it can be instantiated normally. Derived classes also inherit any concrete methods from the abstract base class.

const emp1: Employee = new FullTimeEmployee("Alice", 101, 72000);
const emp2: Employee = new HourlyEmployee("Bob", 102, 35, 160);

console.log(emp1.getDetails()); // Output: Alice (ID: 101)
console.log(emp1.calculatePay()); // Output: 6000

console.log(emp2.getDetails()); // Output: Bob (ID: 102)
console.log(emp2.calculatePay()); // Output: 5600

By specifying Employee as the variable type, both subclasses can be treated polymorphically, ensuring uniform access to shared methods like getDetails() and subclass-specific implementations of calculatePay().
