Dynamic Import Return Type in TypeScript

In TypeScript, dynamic import() statements allow you to load modules asynchronously on demand. This article explains the exact type that dynamic import() resolves to, how TypeScript infers the module's interface, and how to properly type and access both named and default exports.

The Resolved Type: Module Namespace Promise

In a TypeScript project, a dynamic import() call always resolves to a Promise containing the module namespace object. Mathematically, it evaluates to:

Promise<typeof import('./path-to-module')>

When awaited, the resulting value is the module namespace object itself, typed with every named export as a direct property, along with the default export (if one exists) under a .default key.

Example

Consider a file named math.ts:

export const pi = 3.14159;

export function add(a: number, b: number): number {
  return a + b;
}

export default function multiply(a: number, b: number): number {
  return a * b;
}

When dynamically imported:

async function loadMath() {
  const math = await import('./math');
  // Type of `math` is:
  // {
  //   pi: number;
  //   add: (a: number, b: number) => number;
  //   default: (a: number, b: number) => number;
  // }

  console.log(math.pi);
  console.log(math.add(2, 3));
  console.log(math.default(2, 3));
}

Explicitly Typing Module Namespaces

You can capture or reference the type of a module dynamically using TypeScript's type query syntax without executing runtime code:

type MathModule = typeof import('./math');

async function getMathModule(): Promise<MathModule> {
  return await import('./math');
}

This is particularly useful when passing module namespaces as function arguments or storing them in typed registries.

Dynamic Specifiers and Fallback Types

If the module path passed to import() is a variable or cannot be statically analyzed at compile time, TypeScript cannot infer the module's export shape:

const modulePath = './math';
const dynamicModule = await import(modulePath); // Resolves to Promise<any>

In this scenario, import() resolves to Promise<any>. To maintain type safety with runtime-determined paths, explicitly cast the result:

type MathModule = typeof import('./math');

const dynamicModule = (await import(modulePath)) as MathModule;
