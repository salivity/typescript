Narrow Interface Property Types in TypeScript

In TypeScript, a child interface can narrow a property type inherited from a parent interface, provided that the new type is assignable to the original property type. This mechanism relies on subtype polymorphism, allowing developers to refine broad types into more specific ones without breaking contract compatibility. This guide explains how interface property narrowing works, demonstrates valid and invalid implementations, and outlines common use cases.

The Rule of Assignability

When an interface extends a parent interface, TypeScript enforces that every property in the child interface must be assignable to the corresponding property in the parent.

You can narrow a type to any valid subtype. However, you cannot widen a type or replace it with an incompatible type. If the new type is not assignable to the parent type, the TypeScript compiler raises an error indicating that the child interface incorrectly extends the parent interface.

Valid Property Narrowing

A child interface can narrow a property in several ways:

1. Primitive to Literal Type

You can restrict a broad primitive type, such as string or number, to a specific literal or a union of literals.

interface User {
  id: string;
  role: string;
}

interface AdminUser extends User {
  role: "admin"; // Valid: "admin" is assignable to string
}

2. Narrowing Unions

You can reduce the members of a union type to a subset of that union.

interface ApiResponse {
  status: "success" | "error" | "pending";
}

interface CompletedResponse extends ApiResponse {
  status: "success" | "error"; // Valid: subset of the parent union
}

3. Optional to Required Properties

You can make an optional property mandatory in a derived interface.

interface BaseConfig {
  timeout?: number;
}

interface StrictConfig extends BaseConfig {
  timeout: number; // Valid: undefined is no longer permitted
}

4. Narrowing Object Types

A property defined as a general object or a base interface can be narrowed to a more specific interface.

interface Vehicle {
  engine: object;
}

interface ElectricVehicle extends Vehicle {
  engine: {
    batteryCapacityKWh: number;
    motorCount: number;
  }; // Valid: an object literal is assignable to 'object'
}

Invalid Property Narrowing

If you attempt to redefine a property with a type that does not overlap or extend the parent's property type, TypeScript will produce a compilation error.

interface Animal {
  age: number;
}

// Error: Interface 'Pet' incorrectly extends interface 'Animal'.
// Types of property 'age' are incompatible.
// Type 'string' is not assignable to type 'number'.
interface Pet extends Animal {
  age: string;
}

Similarly, you cannot widen a property type in an extended interface:

interface StrictEntity {
  id: string;
}

// Error: Type 'string | number' is not assignable to type 'string'.
interface FlexibleEntity extends StrictEntity {
  id: string | number;
}

Key Takeaways

  • Narrowing is permitted: Child interfaces can refine properties to literals, narrower unions, or derived subtypes.
  • Widening is forbidden: You cannot add types that were not accepted by the parent interface.
  • Assignability governs validity: A property override is valid if, and only if, the new type can be assigned to the parent interface's original property type.
