TypeScript Stage 3 Decorator Context Explained

Modern TypeScript (version 5.0 and later) natively implements the TC39 Stage 3 decorators proposal, moving away from the legacy experimental decorators model. A fundamental component of this updated standard is the decorator context object, which is passed as the second argument to every decorator function. This object provides structured metadata about the decorated entity, offers programmatic access to inspect or mutate values, and provides lifecycle hooks to run initialization logic.

The Role of the Context Object

In the Stage 3 implementation, decorators accept two arguments: the entity being decorated (or undefined for class fields) and the context object. The context object carries runtime and compile-time information about the target, eliminating the need to rely on external reflection libraries like reflect-metadata for basic reflection tasks.

TypeScript models this via specialized interfaces based on the target type, including ClassDecoratorContext, ClassMethodDecoratorContext, ClassFieldDecoratorContext, ClassGetterDecoratorContext, ClassSetterDecoratorContext, and ClassAccessorDecoratorContext.

Core Properties of the Context Object

Regardless of the specific element being decorated, the context object exposes a consistent set of properties:

1. kind

A string literal indicating the type of declaration being decorated. Possible values are:

  • "class"
  • "method"
  • "getter"
  • "setter"
  • "field"
  • "accessor"

This allows generic decorators to validate whether they are being applied to an appropriate target.

2. name

The name of the decorated member, represented as a string or symbol. For a class decorator, this represents the class name or undefined if the class is anonymous.

3. static

A boolean value indicating whether the member is static (true) or belongs to instances of the class (false). This property is undefined on class decorators.

4. private

A boolean flag indicating whether the member is a private class member defined with the # syntax (e.g., #password). This property is undefined on class decorators.

5. access

An object providing direct accessor functions to read or write the member's value, respecting privacy boundaries. It contains:

  • get(object): A function that retrieves the value of the member from the provided instance.
  • set(object, value): A function that sets the value of the member on the provided instance (available for fields, setters, and auto-accessors).

This allows decorators to read and modify private members (#field) without violating language privacy rules.

6. addInitializer

A method that accepts a callback function to be executed during the initialization lifecycle.

  • For classes, the callback runs after the class definition is fully evaluated.
  • For static members, it runs during class definition evaluation.
  • For instance members, it runs when an instance of the class is constructed (before field initializers run).

7. metadata

An optional plain JavaScript object shared across all decorators applied to the same class and its members. It allows decorators to read, write, and share arbitrary metadata throughout the declaration lifecycle.

Example Usage

The following example demonstrates how the context object is utilized inside a method decorator to inspect target details and attach an initialization hook:

function logExecution(
  target: Function,
  context: ClassMethodDecoratorContext
) {
  const methodName = String(context.name);

  context.addInitializer(function () {
    console.log(`Initialized method ${methodName} on instance`);
  });

  return function (this: any, ...args: any[]) {
    console.log(`Executing ${methodName} (Static: ${context.static}, Private: ${context.private})`);
    return target.apply(this, args);
  };
}

class UserService {
  @logExecution
  fetchUser(id: string) {
    return { id, role: "member" };
  }
}

The Stage 3 decorator context standardizes introspection and code execution hooks natively, providing safe, strongly typed access to member metadata within modern TypeScript applications.
