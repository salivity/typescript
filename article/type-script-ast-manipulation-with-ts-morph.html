TypeScript AST Manipulation with ts-morph

Manipulating the TypeScript Abstract Syntax Tree (AST) is essential for building code generators, linters, analyzers, and automated refactoring tools. While the official TypeScript Compiler API provides the foundation for parsing and analyzing TypeScript code, working with it directly is notoriously complex and verbose. This article explains the purpose of ts-morph—a powerful open-source library designed to wrap the TypeScript Compiler API—and details how it streamlines AST traversal, code generation, and source code transformations through an intuitive, developer-friendly interface.

The Challenge with the Native TypeScript Compiler API

The native TypeScript Compiler API represents code as an immutable tree of syntax nodes. While robust, working directly with this native API introduces several challenges:

  • Immutability Overhead: Because native AST nodes are immutable, modifying a node requires rebuilding its parent nodes all the way up to the source file root using syntax factory methods.
  • Complex Navigation: Finding specific nodes (such as a specific method inside a class) requires writing custom recursive tree-walking functions using visitors (ts.forEachChild).
  • Manual String Printing: Converting a modified AST back into source code requires configuring printers, manually handling trivia (whitespace and comments), and managing formatting.
  • Steep Learning Curve: The native API is low-level and sparsely documented for programmatic modification use cases.

What is ts-morph?

ts-morph (formerly ts-simple-ast) is a high-level wrapper built on top of the native TypeScript Compiler API. Its primary purpose is to make AST analysis and code manipulation intuitive, productive, and less error-prone. It abstracts away the low-level mechanics of tree rebuilding and node synchronization, providing a fluent, object-oriented API that treats code elements as mutable objects.

How ts-morph Simplifies AST Manipulation

1. Intuitive Project and File Management

ts-morph introduces a Project class that coordinates compiler options, source files, and file system interactions. Instead of manually creating compiler hosts and programs, a developer can load files, read tsconfig.json, or create in-memory files with minimal setup:

import { Project } from "ts-morph";

const project = new Project();
const sourceFile = project.addSourceFileAtPath("src/example.ts");

2. High-Level Traversal and Querying

Instead of writing AST visitors, ts-morph provides direct querying methods that reflect TypeScript's language constructs:

  • Query nodes directly: sourceFile.getClasses(), sourceFile.getImportDeclarations(), or sourceFile.getFunctions().
  • Find specific members: classDeclaration.getMethodOrThrow("calculateTotal").
  • Use descendants selectors: sourceFile.getDescendantsOfKind(SyntaxKind.Identifier).

These methods return wrapped nodes that carry contextual metadata and helper methods, eliminating the need to cast nodes manually.

3. Direct Node Mutation

The most significant advantage of ts-morph is the ability to mutate the AST directly without manually managing syntax factories or immutability trees. When you update a node, ts-morph automatically calculates the underlying changes, updates the tree, and synchronizes the remaining nodes:

  • Modifying properties: node.rename("newMethodName") handles references and symbols.
  • Adding declarations: classDeclaration.addMethod({ name: "log", parameters: [{ name: "msg", type: "string" }] }).
  • Removing code: methodDeclaration.remove().

4. Automatic Formatting and Trivia Handling

Writing raw AST transformations with the native API often leads to lost comments, stripped whitespace, or poorly formatted output. ts-morph automatically handles indentation, newlines, and surrounding comments (trivia). It also integrates formatting capabilities directly:

sourceFile.formatText({
  indentSize: 2,
});
await project.save();

5. Seamless Type Checker Integration

ts-morph provides straightforward access to the TypeScript type checker. Nodes have direct helper methods to inspect types without resolving symbols manually:

const type = parameter.getType();
console.log(type.getText()); // Outputs the evaluated type
console.log(type.isUnion()); // Boolean check

Primary Use Cases

  • Codemods and Refactoring: Automating large-scale codebase migrations, API deprecations, or renaming patterns.
  • Code Scaffolding: Building CLI tools that dynamically inject routes, controllers, or boilerplate into existing user files.
  • Static Analysis: Auditing codebases for architectural rule violations or missing type annotations.
  • Documentation Generators: Extracting types, JSDoc tags, and signatures from source code without running the compiler output.

By bridging the gap between low-level AST data structures and real-world code manipulation needs, ts-morph reduces the code required for TypeScript AST transformations from hundreds of boilerplate lines to a few readable, chainable operations.
