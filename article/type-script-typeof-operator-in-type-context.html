TypeScript typeof Operator in Type Context

In TypeScript, the typeof operator serves a dual purpose depending on whether it appears in runtime JavaScript code or in a compile-time type context. When used in a type context—such as in a type alias, interface, generic constraint, or type annotation—typeof does not return a runtime string like "string" or "object". Instead, it extracts the static type of an existing variable, constant, or property so you can reference and reuse it across your codebase.

Distinguishing Runtime and Type Contexts

In standard JavaScript, typeof operates on values at runtime:

const count = 42;
const typeName = typeof count; // Evaluates to the string "number" at runtime

In TypeScript's type space, using typeof directly after a type declaration extracts the inferred TypeScript type of an identifier:

const count = 42;
type CountType = typeof count; // Evaluates to the literal type 42 (or number if declared with 'let')

Extracting Complex Object Types

One of the most practical applications of typeof in a type context is generating types automatically from configuration objects or default states. This prevents code duplication and keeps types synchronized with implementation values:

const defaultUserConfig = {
  theme: "dark",
  notifications: true,
  retryAttempts: 3,
};

// Generates an interface matching defaultUserConfig's shape
type UserConfig = typeof defaultUserConfig;

/*
Equivalent to:
type UserConfig = {
  theme: string;
  notifications: boolean;
  retryAttempts: number;
}
*/

Using typeof with Functions

When applied to a function identifier, typeof yields the complete function signature, including parameter types and return type. This is commonly combined with TypeScript utility types such as ReturnType or Parameters:

function calculateTax(amount: number, state: string): number {
  return amount * 0.07;
}

// Extracts the function signature
type TaxFunction = typeof calculateTax; 
// (amount: number, state: string) => number

// Extracts only the return type
type TaxReturn = ReturnType<typeof calculateTax>; 
// number

// Extracts tuple of parameter types
type TaxParams = Parameters<typeof calculateTax>; 
// [amount: number, state: string]

Pairing with as const Assertions

Combining typeof with as const assertions allows you to derive strict, immutable union types directly from runtime arrays or objects:

const HTTP_METHODS = ["GET", "POST", "PUT", "DELETE"] as const;

// Derives a union of string literal types: "GET" | "POST" | "PUT" | "DELETE"
type HttpMethod = (typeof HTTP_METHODS)[number];

Limitations

The typeof operator in a type context only works on declared identifiers (variable names, function names, class names, or properties). It cannot be used directly on the result of an expression or function invocation:

// Valid
const result = runProcess();
type ProcessResult = typeof result;

// Invalid: causes a syntax error
type InvalidType = typeof runProcess();
