TypeScript Include vs Exclude: Precedence Explained

In a TypeScript configuration (tsconfig.json), the include and exclude properties determine which source files are compiled into your project. This article explains the exact precedence rules between include and exclude, how the compiler resolves conflicts when a file matches both arrays, and the specific edge cases where excluded files are still compiled.

The Core Rule: Exclude Overrides Include

When evaluating file glob patterns, exclude takes precedence over include.

TypeScript builds its compilation file list through a two-step filtering process:

  1. It evaluates the glob patterns in include to generate a preliminary list of candidate files. (If include is omitted, it defaults to ["**/*"].)
  2. It evaluates the glob patterns in exclude and removes any matching files from that candidate list.

If a file matches a pattern in both include and exclude, TypeScript will not include it in the compilation set via glob matching. For example, if you include src/**/* but exclude src/**/*.spec.ts, all .spec.ts files inside src are omitted.

If exclude is not specified, TypeScript applies default exclusions for node_modules, bower_components, jspm_packages, and any directory defined in the outDir compiler option.

Critical Exceptions to Exclude Precedence

While exclude takes precedence over include during glob pattern matching, it does not guarantee that a file will never be compiled. Two scenarios override the exclude array:

1. Direct Imports in Code

The exclude array only prevents the compiler from discovering files via directory scanning. If an included file directly imports a file that matches an exclude rule, TypeScript will still parse and compile that excluded file to satisfy type-checking and dependency resolution. To completely isolate a file, it must neither match glob patterns nor be imported by any included file.

2. The files Array

The files property in tsconfig.json defines an explicit list of file paths. It has absolute precedence over exclude. If a file path is specified in files, TypeScript will compile it even if it also matches an entry in exclude.
