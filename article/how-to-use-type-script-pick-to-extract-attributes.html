How to Use TypeScript Pick to Extract Attributes

The Pick utility type in TypeScript provides a type-safe mechanism to construct a new type by choosing a specific subset of properties from an existing type. This article breaks down how Pick works internally using TypeScript's type system features—specifically mapped types, index access types, and the keyof operator—and demonstrates how to apply it in real-world code to create maintainable, DRY (Don't Repeat Yourself) data structures.

The Internal Definition of Pick

TypeScript defines the built-in Pick<Type, Keys> utility type using mapped types and constraints:

type Pick<T, K extends keyof T> = {
    [P in K]: T[P];
};

This definition relies on three core TypeScript mechanics:

  1. keyof T: The keyof operator produces a union of all known property names (keys) belonging to type T.
  2. K extends keyof T: The generic parameter K is constrained using the extends keyword. This ensures that any keys passed into Pick must actually exist on T, triggering a compile-time error if an invalid property name is provided.
  3. [P in K]: T[P]: This is a mapped type syntax. It iterates over each property P in the union of keys K. For each property P, it looks up the original type of that property in T using the indexed access type T[P] and assigns it to the new type.

Practical Example

Consider a comprehensive data model representing a user account in a database:

interface User {
    id: string;
    firstName: string;
    lastName: string;
    email: string;
    passwordHash: string;
    createdAt: Date;
}

If an application view only requires public user information, you can use Pick to extract those exact attributes without redefining their types manually:

type UserPreview = Pick<User, 'firstName' | 'lastName' | 'email'>;

The resulting UserPreview type evaluates directly to:

type UserPreview = {
    firstName: string;
    lastName: string;
    email: string;
};

Key Advantages of Pick

  • Type Safety and Autocompletion: Since K extends keyof T, IDEs provide autocomplete for the available keys, and TypeScript flags an error if a key is misspelled or deleted from the base type.
  • Single Source of Truth: If the type of a property changes in the base interface (for example, if email is updated to a custom EmailAddress type), any derivative types created with Pick automatically inherit the change.
  • Decoupling and Security: It allows developers to quickly define sanitized shapes of data—such as excluding sensitive fields like passwordHash—while preserving exact type definitions across different layers of an application.
