TypeScript Type Guard for Record of Specific Types

Validating unknown runtime data into a strongly-typed dictionary is a common challenge in TypeScript development. This article demonstrates how to create a reusable custom type guard to verify that an unknown value is a valid Record<K, V> with specific key and value types, ensuring safe access without relying on unsafe type assertions.

The Challenge

In TypeScript, Record<K, V> defines an object where property keys are of type K and property values are of type V. Because TypeScript types are erased at compile time, runtime verification is necessary when consuming data from external sources like APIs or configuration files. An incoming unknown value might be null, an array, a primitive, or an object containing invalid value types.

Implementing the Type Guard

To reliably identify a record, you must verify three things at runtime:

  1. The value is a non-null object and not an array.
  2. Every key meets your key constraint (if validating specific keys).
  3. Every corresponding value satisfies your value constraint.

Here is a generic, reusable type guard implementation:

export function isRecord<K extends PropertyKey, V>(
  value: unknown,
  isValidValue: (v: unknown) => v is V,
  isValidKey?: (k: string) => k is K & string
): value is Record<K, V> {
  // 1. Verify the target is a non-null, non-array object
  if (typeof value !== "object" || value === null || Array.isArray(value)) {
    return false;
  }

  // 2. Iterate through all enumerable string keys
  for (const [key, val] of Object.entries(value)) {
    // Validate key if a key guard is provided
    if (isValidKey && !isValidKey(key)) {
      return false;
    }

    // Validate value using the provided value guard
    if (!isValidValue(val)) {
      return false;
    }
  }

  return true;
}

Example Usage

1. Validating a Record of Primitive Values

To check if an unknown input is a Record<string, number> (such as an inventory counter):

const isNumber = (val: unknown): val is number => typeof val === "number";

const data: unknown = { apples: 5, oranges: 10 };

if (isRecord(data, isNumber)) {
  // data is typed as Record<PropertyKey, number>
  console.log(data.apples.toFixed(2));
}

2. Validating a Record of Complex Objects

You can compose the isRecord guard with custom type guards for more complex data structures:

interface UserProfile {
  id: string;
  active: boolean;
}

function isUserProfile(val: unknown): val is UserProfile {
  return (
    typeof val === "object" &&
    val !== null &&
    typeof (val as UserProfile).id === "string" &&
    typeof (val as UserProfile).active === "boolean"
  );
}

const input: unknown = JSON.parse('{"admin": {"id": "1", "active": true}}');

if (isRecord(input, isUserProfile)) {
  // input is typed as Record<PropertyKey, UserProfile>
  console.log(input["admin"].active);
}

3. Validating Specific Keys

If keys must match a specific union rather than arbitrary strings, provide the optional key validator:

type SupportedLanguage = "en" | "es" | "fr";

const isSupportedLanguage = (k: string): k is SupportedLanguage => {
  return ["en", "es", "fr"].includes(k);
};

const translations: unknown = { en: "Hello", es: "Hola" };

if (isRecord(translations, (v): v is string => typeof v === "string", isSupportedLanguage)) {
  // translations is typed as Record<SupportedLanguage, string>
  console.log(translations.en.toUpperCase());
}

By passing modular predicate functions into isRecord, you establish a strict runtime boundary that allows the TypeScript compiler to narrow arbitrary values to verified Record<K, V> structures.
