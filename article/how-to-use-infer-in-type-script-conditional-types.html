How to Use Infer in TypeScript Conditional Types

The infer keyword in TypeScript is a powerful tool used within conditional types to dynamically extract and deduce nested type information. Instead of manually specifying a type variable up front, infer allows the compiler to inspect an existing type—such as the return type of a function, the resolved value of a Promise, or the elements of an array—and declare a local type variable on the fly based on that inspection.

The Syntax of Infer in Conditional Types

Conditional types follow a ternary structure:

T extends Pattern ? TrueBranch : FalseBranch

The infer keyword can only be used within the extends condition (the Pattern part). When placed before a new type variable name, it instructs TypeScript to deduce that specific part of the type.

type ExtractType<T> = T extends SomePattern<infer U> ? U : FallbackType;

If T matches SomePattern, TypeScript populates U with whatever type is in that position and evaluates to U. If T does not match, it evaluates to FallbackType.

Extracting Function Return Types

A standard application of infer is extracting the return type of a function, similar to TypeScript's built-in ReturnType<T> utility.

type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;

type SampleFn = (id: number) => string;
type Result = MyReturnType<SampleFn>; // string

In this example, (...args: any[]) => infer R matches any function signature. The return position is labeled infer R. When SampleFn is provided, TypeScript determines that R corresponds to string.

Unwrapping Array Elements

The infer keyword can also extract the type of elements stored inside an array or tuple.

type Flatten<T> = T extends (infer Item)[] ? Item : T;

type StringArray = string[];
type ExtractedString = Flatten<StringArray>; // string

type PureNumber = Flatten<number>; // number

If T is an array type, infer Item extracts the inner type. If T is a non-array type, the condition falls back to the original type T.

Unwrapping Promises Recursively

Conditional types with infer can be combined with recursion to resolve nested types, such as unwrapping nested Promise types.

type DeepAwaited<T> = T extends Promise<infer Inner> 
  ? DeepAwaited<Inner> 
  : T;

type NestedPromise = Promise<Promise<number>>;
type Unwrapped = DeepAwaited<NestedPromise>; // number

The conditional checks if T is a Promise. If true, it extracts Inner and calls DeepAwaited again until a non-promise type is reached.

Rules and Constraints

  • Placement: infer declarations are only valid in the extends clause of a conditional type.
  • Scope: The inferred type variable is only in scope within the true branch of the conditional type.
  • Multiple Candidates: If an inferred type variable appears in multiple positions within a co-variant position (such as return types), the inferred type will be a union. If it appears in contra-variant positions (such as function arguments), the inferred type will be an intersection.
