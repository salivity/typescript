Async Generator Yield Return Type in TypeScript

In TypeScript, an asynchronous generator function returns an object matching the AsyncGenerator<T, TReturn, TNext> interface, where each generic parameter defines a specific stage of the generator's data exchange. This article breaks down the type signatures governing what an async generator yields, what its internal yield expressions evaluate to, and the structure of the promise returned by invoking .next().

The AsyncGenerator Interface

TypeScript defines the full return type of an asynchronous generator using three generic parameters:

AsyncGenerator<T, TReturn, TNext>
  • T (Yield Type): The type of values emitted using the yield keyword.
  • TReturn (Return Type): The type of the final value returned via the return statement (or void if nothing is returned).
  • TNext (Next Type): The type of values accepted by the generator when callers invoke .next(value). This is the evaluated type of the yield expression inside the generator function.

If omitted, TReturn and TNext typically default to void and unknown, respectively.

The .next() Return Signature

Calling .next() on an asynchronous generator produces a Promise resolving to an IteratorResult:

next(...args: [] | [TNext]): Promise<IteratorResult<T, TReturn>>;

The IteratorResult<T, TReturn> is a discriminated union representing either an intermediate yield or the final return:

type IteratorResult<T, TReturn> = 
  | IteratorYieldResult<T> 
  | IteratorReturnResult<TReturn>;

interface IteratorYieldResult<T> {
  done: false;
  value: T;
}

interface IteratorReturnResult<TReturn> {
  done: true;
  value: TReturn;
}

When yielding, the promise resolves to { done: false, value: T }. When terminating via return, the promise resolves to { done: true, value: TReturn }.

The Type of the yield Expression

Inside the body of the generator, the yield expression acts as an input point. Its evaluated type corresponds to TNext:

async function* example(): AsyncGenerator<number, string, boolean> {
  // 'received' is typed as boolean (TNext)
  // '100' must match number (T)
  const received: boolean = yield 100; 

  // 'done' must match string (TReturn)
  return "Finished";
}

Common Simplified Signatures

When an asynchronous generator only emits values and does not process incoming inputs via .next() or provide a custom final return value, TypeScript allows simpler interfaces:

  • AsyncIterableIterator<T>: Equivalent to AsyncGenerator<T, void, unknown>, commonly used when the generator will only be consumed using for await (... of ...).
  • AsyncIterable<T>: The minimal protocol required for for await...of loops, guaranteeing only the presence of [Symbol.asyncIterator]().
