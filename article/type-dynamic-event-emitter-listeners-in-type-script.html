Type Dynamic Event Emitter Listeners in TypeScript

By default, standard event emitters in JavaScript and Node.js rely on string identifiers and arbitrary callback arguments, leading to an absence of type safety that can introduce runtime bugs. This article explains how to build a strongly typed dynamic event emitter in TypeScript using generic interfaces, mapped types, and key constraints. By defining an event-to-payload map, you can ensure that event names provide auto-completion and that listener callbacks automatically resolve to their correct, dynamically typed payloads.

Defining the Event Map

The foundation of type-safe event emitters is an interface that maps event names to their expected parameter payloads. Represent arguments as tuples to accommodate events that pass multiple arguments:

export interface AppEvents {
  userLoggedIn: [userId: string, timestamp: number];
  userLoggedOut: [userId: string];
  error: [error: Error];
  cacheCleared: []; // No arguments
}

Creating a Strongly Typed EventEmitter Interface

Instead of typing event names as arbitrary strings, restrict event names to keyof AppEvents and bind listener parameters directly to the corresponding tuple types:

export interface TypedEventEmitter<Events extends Record<string, any[]>> {
  on<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this;
  once<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this;
  emit<K extends keyof Events>(event: K, ...args: Events[K]): boolean;
  off<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this;
  removeListener<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this;
}

Implementing with Node.js EventEmitter

You can back this interface using the standard Node.js EventEmitter. The cleanest approach is extending the standard class while casting the methods to your strictly typed signatures:

import { EventEmitter } from 'events';

export class StrictEventEmitter<Events extends Record<string, any[]>> extends (EventEmitter as new () => TypedEventEmitter<Events>) {}

Alternatively, if you prefer composition to avoid inheritance complexities:

import { EventEmitter } from 'events';

export class TypedEmitter<Events extends Record<string, any[]>> {
  private emitter = new EventEmitter();

  on<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this {
    this.emitter.on(event as string, listener as (...args: any[]) => void);
    return this;
  }

  emit<K extends keyof Events>(event: K, ...args: Events[K]): boolean {
    return this.emitter.emit(event as string, ...args);
  }

  off<K extends keyof Events>(event: K, listener: (...args: Events[K]) => void): this {
    this.emitter.off(event as string, listener as (...args: any[]) => void);
    return this;
  }
}

Handling Dynamic and Extensible Event Maps

If your application registers dynamic events at runtime or combines modules with different event sets, leverage generic intersection types or generic inheritance:

// Base emitter instance instantiated with dynamic extensions
function createScopedEmitter<CustomEvents extends Record<string, any[]>>() {
  type CombinedEvents = AppEvents & CustomEvents;
  return new TypedEmitter<CombinedEvents>();
}

// Defining a scoped module
interface PluginEvents {
  pluginLoaded: [pluginName: string];
}

const emitter = createScopedEmitter<PluginEvents>();

// Type-safe dynamic listeners
emitter.on('pluginLoaded', (name) => {
  // TypeScript infers `name` as string
  console.log(`Loaded: ${name}`);
});

emitter.on('userLoggedIn', (userId, timestamp) => {
  // TypeScript infers `userId` as string and `timestamp` as number
  console.log(`User ${userId} logged in at ${timestamp}`);
});

Compile-Time Validation

When using this pattern, TypeScript validates the relationship between the event name and listener parameters:

// Compiler Error: Argument of type 'number' is not assignable to parameter of type 'string'.
emitter.emit('userLoggedOut', 12345);

// Compiler Error: Argument of type '"invalidEvent"' is not assignable to parameter of type 'keyof CombinedEvents'.
emitter.on('invalidEvent', () => {});

This pattern eliminates manual casting inside listener callbacks and surfaces breaking changes immediately whenever an event's payload signature is modified.
