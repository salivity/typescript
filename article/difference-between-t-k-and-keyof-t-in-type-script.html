Difference Between T[K] and keyof T in TypeScript

In TypeScript, keyof T and T[K] are fundamental type manipulation tools that work with object types, but they serve inverse purposes. While keyof T is the index type query operator used to extract the property names (keys) of an object as a union of literal types, T[K] is an indexed access type used to look up the type of a property (value) corresponding to a specific key. Understanding the difference between extracting keys and accessing value types is essential for writing robust generic code.

What is keyof T?

The keyof operator takes an object type T and produces a string or numeric literal union of its keys. It tells you what property names are valid on that type.

type User = {
  id: number;
  name: string;
  isActive: boolean;
};

// Result: "id" | "name" | "isActive"
type UserKeys = keyof User;

In this example, keyof User inspects the structure of User and outputs a union containing the names of its fields.

What is T[K]?

The T[K] syntax represents an indexed access type, often called a lookup type. It queries the type of the value stored at a specific property K within the type T.

type User = {
  id: number;
  name: string;
  isActive: boolean;
};

// Result: string
type UserName = User["name"];

// Result: number | boolean
type UserIdOrStatus = User["id" | "isActive"];

Here, User["name"] evaluates directly to string, reflecting the type of the value that name holds. If you pass a union of keys into K, the result is a union of the corresponding property types.

Core Differences

Feature keyof T T[K]
Concept Index type query Indexed access / lookup type
Target Extracts the keys of T Extracts the value types of T at key K
Input A single object type T A type T and an indexing key type K
Output Union of string, number, or symbol literals The specific type(s) associated with key K

How They Work Together

keyof T and T[K] are most powerful when combined in generic constraints. A common pattern is creating a type-safe property getter function where keyof T restricts the input parameter to valid keys, and T[K] ensures the function returns the exact value type for that key.

function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user: User = {
  id: 1,
  name: "Alice",
  isActive: true,
};

// Type of 'userName' is inferred as string
const userName = getProperty(user, "name");

// Type of 'userId' is inferred as number
const userId = getProperty(user, "id");

In this implementation, K extends keyof T guarantees that you can only pass existing keys of user to the function, while the return type T[K] ensures that TypeScript infers the exact return type based on the key provided.
